# AI usage

При подготовке учебного проекта использовался ИИ для помощи в разборе требований, проектировании структуры и пояснении кода.

Перед сдачей студент должен самостоятельно прочитать проект, запустить тесты и убедиться, что понимает валидацию, обработку дубликатов и работу анализаторов. Укажите фактическое использование ИИ в соответствии с правилами преподавателя.
